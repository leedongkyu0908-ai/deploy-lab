## 남은 한계
- **배포 검증 안 함(조건 5).** 공개 API·휴대폰 화면 확인과 그때의 커밋·시각 기록이 남았다.
- **커밋 전 상태에서 검증.** 커밋 후 같은 결과인지 다시 확인해야 커밋 동일성을 말할 수 있다.
- **길이 기준은 JavaScript `length`(UTF-16 코드 단위).** 이모지·결합 문자는 눈에 보이는 글자 수와 다르게 셀 수 있다(예: 이모지 1개가 2자). 스펙대로 한글·영문으로만 경계를 확인했다.
- **기존 메모는 그대로 둔다.** 20자 규칙 전에 저장된 20자 초과 메모가 있어도 지우거나 자르지 않는다. 현재 DB에는 20자 초과 메모가 없다.
- 검증 중 추가한 메모(id 7·8·9·10·11)는 실제 행으로 남아 있다. 최종 확인 시 `length(body) > 20`인 행은 0개.

로컬·배포 결과를 구분한다. 검증 스크립트는 메모를 실제 추가한다. 원래 데이터는 삭제하지 않는다.
